THE PROBLEM

Water systems run blind.

Most tanks and pipelines are only checked when something has already gone wrong.

01

Wastage goes unnoticed

Small leaks and overflows run for days before anyone spots them.

02

Quality is checked too late

Contamination is usually discovered after it reaches a household or tank.

03

Management is manual

Levels are read by eye and pumps switched by hand — no data trail, no early warning.

SYSTEM PIPELINE

From sensor to decision, in four stages.

Raw readings become an action — an alert, a pump switch, a logged trend — without anyone checking a tank by hand.

01

Sense

Ultrasonic level sensors, pH and turbidity probes, and flow meters take continuous readings.

Ultrasonic level sensorpH / TDS probeTurbidity sensorFlow meter
02

Process

A microcontroller at each node reads the sensors and flags anything abnormal before it's sent onward.

ESP32 / Arduino UNOEdge threshold checks
03

Transmit & store

Readings travel to a cloud database, building a continuous, timestamped history for every point.

MQTT / HTTPTime-series log
04

Act

The dashboard visualises live status, sends alerts, and can trigger a pump or valve automatically.

Live dashboardSMS / app alertAuto pump control
CORE CAPABILITIES

Three things the system watches at once.

Water level monitoring

Tracks tank levels continuously, so supply is never a guess.

  • Real-time fill percentage
  • Auto motor cut-off on overflow
  • Low-level early warning

Water quality monitoring

Checks pH, turbidity and dissolved solids around the clock.

  • pH and TDS tracking
  • Turbidity / contamination flag
  • Instant unsafe-reading alert

Leakage detection

Compares expected vs. actual flow to catch leaks before they're visible.

  • Flow-mismatch detection
  • Pressure-drop alerts by zone
  • Notification the moment it starts

PROTOTYPE — CIRCUIT REFERENCE

HC-SR04 + Arduino UNO + 16×2 LCD

The working prototype behind AquaWatch: an ultrasonic sensor reads tank level, a simulated flow sensor watches for leaks, and an I2C LCD plus LED/buzzer panel report status in real time.

  • 01 Arduino UNO
  • 02 HC-SR04 ultrasonic sensor — water level
  • 03 YF-S201 water flow sensor — leakage (simulated via potentiometer 2)
  • 04 16×2 LCD display (I2C)
  • 05 2 × potentiometers — water quality & flow
  • 06 Buzzer — audible alert
  • 07 3 × LEDs — green / yellow / red status
  • 08 Jumper wires
  • 09 Breadboard (optional)
  • 10 Resistors — 220Ω × 3
  • 11 USB cable / power supply
